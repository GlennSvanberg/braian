# OpenPIM (arbetsnamn)

Öppen källkod (MIT), self-hosted datahanteringssystem för det PIM brukar användas till.
Färdiga gränssnitt som ett traditionellt PIM, men allt nåbart via API och MCP.

Status: tidigt skede. Inget är körbart än utöver utvecklingsmiljön.
